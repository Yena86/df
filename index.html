1. 실험 개요

한 번에 하나의 변인만 바꾸어 결과 차이를 해석했다.

연구 목적

이미 학습된 diffusion model에서 prompt와 생성 파라미터가 이미지 결과에 미치는 영향을 관찰한다.

핵심 원칙

prompt, seed, step, guidance 중 하나만 바꾸고 나머지는 고정하여 원인을 분명히 한다.

평가 기준

prompt 반영도, 선명도, 이상한 부분, 다양성, 일관성을 기준으로 비교한다.

2. 주요 용어

보고서 앞부분에 넣으면 보는 사람이 실험을 이해하기 쉽다.

Prompt

AI에게 원하는 이미지를 설명하는 문장이다.

Seed

이미지 생성을 시작하는 랜덤 노이즈를 정하는 값이다.

Step

노이즈를 제거하는 반복 횟수이다.

Guidance scale

AI가 prompt를 얼마나 강하게 따를지 정하는 값이다.

Negative prompt

이미지에서 피하고 싶은 특징을 입력하는 문장이다.

Diffusion model

랜덤 노이즈에서 시작해 점점 노이즈를 제거하며 이미지를 만드는 모델이다.

Pretrained

이미 많은 데이터로 학습되어 바로 사용할 수 있는 상태를 말한다.

MNIST DDPM

숫자 라벨을 조건으로 사용하는 작은 diffusion 실험 모델이다.

3. 실험 결과 카드

사진 원본 대신 결과를 글로 요약했다. 카드의 “자세히”를 누르면 조건과 해석이 펼쳐진다.

4. 핵심 비교

실험 전체를 한눈에 정리한 표이다.

변인 주로 바뀐 부분 결론
Seed구도, 로봇 모양, 자세, 색감같은 prompt에서도 다양한 결과를 만든다.
Step선명도와 세부 표현어느 정도는 도움이 되지만 무조건 많을수록 좋은 것은 아니다.
Guidance scaleprompt 반영 강도, 색감, 자연스러움너무 크면 이미지가 부자연스럽고 거칠어진다.
색깔 단어자동차 색상과 전체 분위기단어 하나도 결과에 직접 영향을 준다.
스타일 단어그림체, 질감, 분위기대상은 유지되지만 표현 방식이 크게 바뀐다.
Negative prompt피하고 싶은 특징항상 뚜렷한 차이를 만들지는 않는다.

6. 최종 결론

중3 보고서에 바로 넣기 좋은 문장이다.

이번 실험을 통해 이미지 생성 AI는 prompt와 설정값에 따라 결과가 크게 달라진다는 것을 알 수 있었다. Seed는 이미지의 세부 모습과 구도를 바꾸었고, step과 guidance scale은 적절한 값일 때만 도움이 되었다. 또한 색깔과 스타일 단어 하나만 바꾸어도 이미지의 분위기가 크게 달라졌다. 따라서 좋은 이미지를 만들기 위해서는 구체적인 prompt와 적절한 설정값 조절이 중요하다.
